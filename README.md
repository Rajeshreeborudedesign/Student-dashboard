# Student Record & Academic Management System

## Project Description
A console-based Student Record & Academic Management System developed using Python.

## Features
- Add Student
- Search Student
- Update Student
- Delete Student
- Display Student Records
- Calculate Average Marks
- Find Highest Scorer
- List Students by Department
- Count Students
- Generate Reports

## Technologies Used
- Python
- Jupyter Notebook

## Python Data Structures
- String
- List
- Tuple
- Set
- Dictionary

## Project Files
- string_programs.ipynb
- list_programs.ipynb
- tuple_programs.ipynb
- set_programs.ipynb
- dictionary_programs.ipynb
- integrated_system.ipynb
- algorithms.ipynb
- pseudocode.ipynb
- flowcharts.ipynb
- testing.ipynb
- documentation.ipynb

## How to Run
1. Open Jupyter Notebook.
2. Open integrated_system.ipynb.
3. Run the main program cell.
4. Select the required operation from the menu.
5. Enter 0 to exit.
